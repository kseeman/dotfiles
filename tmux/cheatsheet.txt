tmux cheatsheet                                   prefix is C-b, then the key
===============                                   q to close, / to search here

HELP
  ?            this cheatsheet
  /            fuzzy-search every binding
  r            reload tmux.conf
  :            command prompt

PANES
  |            split left/right
  -            split top/bottom
  h j k l      move to pane left / below / above / right
  H J K L      resize (repeatable: hold C-b once, press several times)
  z            zoom pane (toggle)
  x            close pane
  !            break pane out into its own window
  q            show pane numbers

WINDOWS
  c            new window
  1 .. 9       go to window N
  n / p        next / previous window
  ,            rename window
  w            window and session tree
  &            close window

SESSIONS
  f            fuzzy-find a project and switch to its session
  s            session tree
  Space        last session (toggle)
  ( / )        previous / next session
  N            new session (prompts for a name)
  $            rename session
  X            kill this session
  d            detach
  C-s / C-r    save / restore all sessions (tmux-resurrect)

GIT
  g            lazygit, in a popup, at the current pane's directory

COPY MODE
  [            enter copy mode (scroll with the mouse, or j/k, C-u/C-d)
  v            start selection
  C-v          toggle rectangle selection
  y            yank to the system clipboard and leave copy mode
  / ?          search forward / backward
  q            leave copy mode

PLUGINS (tpm)
  I            install plugins declared in tmux.conf
  U            update plugins
  M-u          remove plugins no longer declared

FROM THE SHELL
  tmux                 start a new session
  tmux a               re-attach to the last session
  tmux ls              list sessions
  dev                  pick a project and enter its workspace
  dev <name>           go straight there when the name is unambiguous
  dev -                back to the last session, no picker
  tmux-sessionizer     what dev and prefix + f both run

IN THE PROJECT PICKER (dev, or prefix + f)
  ●  /  ○      has a running session / doesn't; running ones sort first
  enter        open it
  ctrl-x       kill that project's session, list refreshes in place
  ctrl-/       show / hide the preview (git state and README)

A PROJECT WORKSPACE
  New sessions open two windows: editor (nvim running) and shell. To give one
  project a different layout, drop an executable script at
  ~/.userconfig/tmux/layouts/<session-name>; it is passed the session name, the
  project directory and the pinned nvim profile, and takes over from there.

  To pin which nvim profile a project opens with, write the profile name into
  ~/.userconfig/tmux/profiles/<session-name>:

    echo java > ~/.userconfig/tmux/profiles/acme-api

  It applies to every pane in that session, and is set when the session is
  created — change it and you need to kill the session (^x in the picker) and
  reopen for it to take effect.

IN NEOVIM
  Starting nvim with no file shows the dashboard. s restores this directory's
  session, p switches project. <leader>qs restores from anywhere.
